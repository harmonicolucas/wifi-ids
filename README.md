# Detecção de Ataques em Redes Wi-Fi Públicas

Projecto apresentado na feira do ISUTC sobre **detecção de ataques em redes Wi-Fi públicas** (evil twin, deauthentication, ARP spoofing, rogue AP).

O trabalho cobre monitorização de pontos de acesso, classificação de eventos e alerta em tempo real, com aplicação ao contexto de Maputo.

Notícia: [ISUTC](https://www.isutc.ac.mz/?p=11780)
